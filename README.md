# Финансовый помощник (Finance Assistant)

Веб-приложение для учёта личных финансов: доходы, расходы по категориям, инвестиции, с возможностью переключения по месяцам и построения графиков.

## 🚀 Основные возможности

- **Управление доходами** – добавление, просмотр, удаление записей по датам.
- **Расходы** – древовидная структура категорий, прогноз (бюджет) и фактические траты (по дням).
- **Инвестиции** – древовидная структура с суммами по категориям.
- **Переключение месяцев** – данные хранятся отдельно для каждого месяца.
- **Графики** – столбчатые, круговые, линейные диаграммы по выбранным категориям.
- **Логирование** – запись действий в файлы в папке `logs/`.

## 🛠️ Технологии

- **Python 3.10+**
- **NiceGUI** – для UI (на основе FastAPI/Uvicorn)
- **JSON** – хранение данных (без БД)
- **Встроенные библиотеки** – `json`, `os`, `datetime`

## 📦 Установка и запуск

```bash
# Клонируйте репозиторий
git clone <url>
cd financial

# Создайте и активируйте виртуальное окружение
python3 -m venv venv
source venv/bin/activate      # Linux/Mac
# или venv\Scripts\activate   # Windows

# Установите зависимости
pip install -r requirements.txt

# Запустите веб-приложение
python3 webapp.py
```

После запуска откройте в браузере: [http://127.0.0.1:8080](http://127.0.0.1:8080)

## ⚠️ ВАЖНО: файл данных

Для корректной работы **обязательно** наличие папки `data/` и файла `finance_data.json` внутри неё.  
Если файл отсутствует или повреждён, приложение упадёт с ошибкой `ValueError: Invalid value: ...`.

### Создайте файл-болванку вручную:

Создайте папку `data` в корне проекта и в ней файл `finance_data.json` со следующим содержимым (замените `"2026-08"` на текущий месяц в формате `ГГГГ-ММ`):

```json
{
  "months": {
    "2026-08": {
      "incomes": {},
      "expenses": {},
      "investments": {}
    }
  },
  "current_month": "2026-08"
}
```

В дальнейшем приложение будет автоматически создавать недостающие месяцы при сохранении, но **первый запуск требует этого файла**.

## 📁 Структура проекта

```
financial/
├── data/                   # данные (JSON)
├── logs/                   # логи
├── core/                   # бизнес-логика (состояние, операции с месяцами, отчёты)
├── ui/                     # интерфейс (вкладки, диалоги)
├── storage.py              # загрузка/сохранение JSON
├── models.py               # модели данных (дерево категорий)
├── operations.py           # CRUD-операции
├── logger.py               # логирование
├── webapp.py               # точка входа
├── cli.py                  # консольная версия (для тестов)
├── requirements.txt        # зависимости
└── README.md               # этот файл
```
